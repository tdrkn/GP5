## **Бизнес-контекст:**
Аварии с пострадавшими - самые дорогие случаи для страховой компании:
- **Медицинские расходы и выплаты по жизни** кратно выше, чем компенсация за повреждение автомобиля
- **Тяжесть ДТП** сейчас выясняется **постфактум, вручную** при разборе заявки
- Это тормозит **финансовое планирование** и **приоритезацию выплат**

**Заказчик:** Страховая компания, обрабатывающая заявки по автострахованию

**Цель:** Создать единый скоринг страховой заявки, который:
- По **фотографии автомобиля** оценивает видимые повреждения
- По **табличным данным** (погода, дорога, участники, тип столкновения) оценивает риск пострадавших

## Задача 1: Табличные данные (прогноз пострадавших в ДТП)

### Постановка
Страховая компания хочет заранее оценивать, какие ДТП с большей вероятностью приводят к травмам или смерти.

**Целевая переменная** (бинарная):
- **0** — авария без пострадавших (только материальный ущерб)
- **1** — авария с пострадавшими или летальным исходом

**Входные признаки:**
- Погодные условия
- Освещение
- Тип дороги
- Район
- Тип столкновения
- Состав участников (водитель/пассажир/пешеход)
- Тип транспортного средства (авто/мото/вело/автобус)

### Данные
- **Источник:** [Cincinnati Car Crash Data](https://data.cincinnati-oh.gov/bc9j-hgu6)
- **Объём:** около 107K аварий и 258K участников
- **Особенность:** одна строка = один участник аварии
- **Дисбаланс:** смертельных случаев крайне мало, задача сведена к бинарной классификации (есть/нет пострадавших)

### Почему полносвязная нейронная сеть?
- Данные представлены набором признаков (таблица)
- MLP автоматически находит сложные нелинейные зависимости без ручного конструирования признаков
- Для контроля качества сравниваем с сильным классическим ML (CatBoost/LightGBM)

## Задача 2: Изображения (обнаружение повреждений авто)

### Постановка
Автоматическое определение наличия повреждений на фотографии автомобиля для ускорения первичной проверки заявок.

**Целевая переменная:** `Condition`
- **0** — автомобиль без видимых повреждений
- **1** — автомобиль с видимыми повреждениями

**Входные данные:** RGB-изображение автомобиля

### Данные
- **Источник:** [Fast, Furious and Insured](https://www.kaggle.com/datasets/infernape/fast-furious-and-insured)
- **Структура:**
  - `train.csv` — 1399 строк, 8 столбцов
  - `trainImages/` — 1399 фотографий
  - `testImages/` — 600 фотографий
- **Особенности:**
  - Сильный дисбаланс: 92.9% повреждённых, 7.1% целых
  - Изображения разного размера и пропорций

### Модели
| Модель | Параметры | Тип | Причина выбора|
|--------|-----------|-----|---------------|
| BaselineCNN | 0.09M | Обучена с нуля | В качестве точки отсчета. Простая сверточная сеть, чтобы оценить нижнюю границу качества и убедиться, что более сложные модели дают прирост  |
| EfficientNet-B0 | 5.3M | Предобучена | Модель позволяет балансировать между точностью, размером модели и вычислительными затратами - улучшает работу со всеми показателями | 
| ConvNeXt-Atto | 3.7M | Предобучена | Модель имеет не так много параметров, и компромиссна в семействе относительно требовательности к ресурсам. Сочетает идеи ViT и CNN  | 

### Финальная модель 
| Параметр | Выбор |
|----------|-------|
| Архитектура | ConvNeXt-Atto  |
| Предобработка | ResizeWithPadding (сохранение пропорций) |
| Балансировка | WeightedRandomSampler |
| Обучение | Fine-tuning всех слоёв (4 эпохи, lr=1e-5) |
| Порог классификации | 0.31 (подобран по macro F1) |

**Финальное качество:**
- Accuracy: 94.6%
- Balanced Accuracy: 81.7%
- Macro F1: 0.808
- F1 (класс 0): 0.645
- ROC-AUC: 0.88
